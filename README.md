# Carta de Smith (Obsidian)

Vista interactiva de la carta de Smith: zoom, puntos e historial, integrada con el tema de Obsidian.

## Instalación (desarrollo)

1. `npm install && npm run build`
2. Copia o enlaza esta carpeta a `<vault>/.obsidian/plugins/smith-chart/`
3. En Obsidian: Settings → Community plugins → activa **Carta de Smith**
4. Comando: **Abrir carta de Smith** (o el icono del ribbon)

## Uso

- **Rueda**: zoom (la cuadrícula se densifica)
- **Arrastrar**: pan
- **Click**: fija un punto (aparece en el HUD y se desvanece en 3 s; máx. 3 visibles)
- **Historial**: todos los puntos de la sesión
- **Reset zoom**: vuelve a la vista inicial
